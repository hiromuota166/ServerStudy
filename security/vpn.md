# VPN と Tailscale

## ひとことで言うと
VPN（Virtual Private Network）は、インターネットの上に作る「自分たち専用の、外から中が見えないトンネル」。トンネルの中では、離れた場所の機器同士が同じ家の Wi-Fi にいるかのように通信できる。

## 仕組み
- インターネットは誰でも通れる公道。VPN はその中に、暗号化した専用のトンネルを掘るイメージ
- トンネルの中だけで使える住所（Tailscale なら `100.x.x.x`）が配られる。これはプライベート IP の仲間なので、トンネルに入っていない他人からは届かない
- だから「自分だけがどこからでも見られる」状態になる

### Tailscale でつながるまで
```
        Tailscale の調整サーバー（住所と鍵を交換するだけ）
           ↕ 最初の準備            ↕ 最初の準備
iPhone（モバイル回線）  ⇄ 暗号化トンネル ⇄  Ubuntu（自宅・NAT の奥）
```
1. iPhone と Ubuntu が、それぞれ調整サーバーに「今ここにいます。これが鍵です」と登録する
2. お互いの居場所がわかったので、iPhone と Ubuntu が直接、暗号化した通信を始める
3. iPhone が `100.x.x.x` に送ったデータは、トンネルを通って Ubuntu の nginx に届く

- **NAT の奥にいても届く理由**：Ubuntu のほうから外に向かって接続しにいくので、NAT の壁（外から中へは入れない）を越えられる。ポートフォワーディングもいらない
- **調整サーバーはつなぎ役だけ**：暗号化の鍵は iPhone と Ubuntu だけが持っているので、データの中身は見られない

### 会社の VPN との違い
| | 会社の VPN | Tailscale |
|---|---|---|
| つながり方 | 全員が会社の入口（VPN サーバー）を通って、社内ネットワークに入る | 機器同士が直接つながる（メッシュ型） |
| 目的 | 社外から社内のシステムを使う | 自分の機器同士をつなぐ |
| 仕組み | 同じ（暗号化したトンネル + プライベート IP） | 同じ |

会社で VPN をつなぐと社内のシステムが見えるのも、ノート PC が「会社のネットワークの中にいる」扱いになるから。

### Lv2 の構成での役割
Tailscale は「管理用の入口」として使う（踏み台サーバーと同じ役割）。

```
世界中の誰でも ──（Cloudflare Tunnel / HTTPS）──→ nginx → 自作アプリ   … 公開用の道
自分だけ ────────（Tailscale）───────────────→ ssh                    … 管理用の道
```
「公開用の道と管理用の道を分けて、ssh はインターネットに出していない」と説明できる。

## 自分の環境では
- Ubuntu に入れる
  ```bash
  curl -fsSL https://tailscale.com/install.sh | sh
  sudo tailscale up
  ```
  表示された URL を Windows のブラウザで開いてログインする
- iPhone は App Store の「Tailscale」アプリで、同じアカウントにログインする
- `tailscale ip -4` で Tailscale 用の IP（`100.x.x.x`）を確認する
- iPhone の Wi-Fi をオフにして（モバイル回線で）`http://100.x.x.x` を開き、nginx のページが見えた
