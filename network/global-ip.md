# グローバル IP とプライベート IP

## ひとことで言うと
グローバル IP は、インターネット上で使える世界で1つだけの住所。自宅では **Wi-Fi ルーターが1つだけ** 持っていて、プロバイダから借りている。Ubuntu も Windows も、持っているのはプライベート IP だけ。

## 仕組み

### 見分け方：プライベートの始まり方だけ覚える
グローバル IP には「この数字から始まる」という決まりはない。**プライベート IP の始まり方が決まっていて、それ以外がだいたいグローバル**。

| 種類 | 始まり | 例 |
|---|---|---|
| プライベート | `10.` | `10.0.0.5`（会社でよく使う） |
| プライベート | `172.16.` 〜 `172.31.` | `172.31.251.31`（最初に Default Switch で Ubuntu に付いた IP） |
| プライベート | `192.168.` | `192.168.100.10`（Ubuntu）、`192.168.11.10`（Windows） |
| グローバル | 上記と下の特別な番号以外 | `185.125.190.20`（ubuntu.com）、`1.1.1.1`（Cloudflare）、`8.8.8.8`（Google） |

### どちらでもない特別な番号
| 始まり | 用途 |
|---|---|
| `127.` | 自分自身（localhost） |
| `100.64.` 〜 `100.127.` | プロバイダの NAT（CGNAT）や Tailscale 用。Tailscale の `100.114.194.19` もこれ |
| `169.254.` | DHCP で IP がもらえなかったときに自動で付く（トラブルのサイン） |
| `203.0.113.` など | 説明用に予約されている番号（実在しない例）。NAT の動画で使った `203.0.113.5` |

### サーバーを公開していなくても、グローバル IP はある
グローバル IP は「インターネットを使うため」に必要なもの。外と通信するときは、送り主の欄にグローバル IP が書かれる（→ [NAT](nat.md)）。これがないと、相手は返事を返せない。

なので、**家でインターネットが使えている ＝ ルーターがグローバル IP を持っている**。

| | 家のたとえ | ネットワーク |
|---|---|---|
| 住所がある | 手紙を出したり、返事を受け取ったりできる | グローバル IP がある（**今の状態**） |
| お店を開く | 看板を出して、知らない人も入れるようにする | サーバーを公開する（**まだやっていない**） |

今は「住所はあるけど、知らない人が入れる入口がない」状態。ルーターでポートを開けていないので、外から来た通信は捨てられる。

### CGNAT
プロバイダによっては、ルーターすら本当のグローバル IP を持っていないことがある。プロバイダ側でもう1回 NAT している状態で、CGNAT（キャリアグレード NAT）と呼ぶ。ルーターの管理画面に出る外側（WAN 側）の IP と、`curl.exe ifconfig.me` の結果が違えば、この状態。

この場合、ルーターでポートを開けても外からは入れない。ただ、Cloudflare Tunnel や Tailscale は中から外に接続しにいく仕組みなので、問題なく使える。

## 自分の環境では

| 機器 | 持っている IP | 種類 |
|---|---|---|
| 自宅ルーター | **グローバル IP（1つだけ）** と `192.168.11.1` | グローバル + プライベート |
| Windows | `192.168.11.10`（Wi-Fi 側）と `192.168.100.1`（NATSwitch 側） | プライベートだけ |
| Ubuntu | `192.168.100.10` | プライベートだけ |
| Ubuntu（Tailscale） | `100.114.194.19` | Tailscale の中だけで届く住所 |

外から見た自分の住所（ルーターのグローバル IP）を確認するコマンド（PowerShell）：

```powershell
curl.exe ifconfig.me
```

自分の機器のどれにもない番号が出る。グローバル IP はプロバイダから借りているものなので、ルーターを再起動すると変わることがある（→ DDNS が必要になる理由）。

### 上司に聞かれたら
> グローバル IP を持っているのは自宅の Wi-Fi ルーターで、プロバイダから1つ割り当てられています。インターネットを使うために、もともとあるものです。Ubuntu はプライベート IP（`192.168.100.10`）しか持っていなくて、外に出るときは Windows とルーターで2回 NAT されます。ルーターでポートを開けていないので、外からサーバーに入れる入口はありません。
